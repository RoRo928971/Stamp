# ✍️ PDFサインアプリ

会社の書類(PDF)を取り込み、選択した箇所に手書きのサインを記入できるブラウザアプリです。

## 特長

- **完全クライアントサイド処理** — PDFファイルはブラウザ内だけで処理され、サーバーや外部に送信されません。機密書類でも安心して利用できます。
- **2種類のサイン入力** に対応
  - その場で手書き(マウス・タッチペン・指)。ペンの色と太さを変更可能
  - 手持ちのサイン画像・印鑑画像(PNG / JPG)をアップロード
- **クリックで記入**、ドラッグで移動、スライダーでサイズ調整
- **複数ページ対応**、ページの回転(90°/180°/270°)にも対応
- サインの取り消し・全消去、サイン済みPDFのダウンロード

## 使い方

1. このフォルダの `index.html` をブラウザで開きます。
2. **① PDFを取り込む** — PDFファイルを選択(またはドラッグ&ドロップ)します。
3. **② サインを準備する**
   - 「手書きサイン」タブ：枠内にサインを書き、色・太さを調整して「このサインを使う」を押します。書き直すときは「消去」を押します。
   - 「画像を使う」タブ：サイン画像を選択します(背景が透明なPNG推奨)。
4. **③ サインする** — PDF上のサインしたい位置をクリックします。配置後はドラッグで移動、スライダーでサイズ変更できます。サイン右上の「×」で個別削除できます。
5. **④ 保存する** — 「サイン済みPDFをダウンロード」を押すと、サインを焼き込んだPDFが保存されます。

## 動作環境

- モダンなブラウザ(Chrome / Edge / Firefox / Safari の最新版)
- 表示にインターネット接続が必要です(PDF描画ライブラリ [PDF.js](https://mozilla.github.io/pdf.js/) と PDF生成ライブラリ [pdf-lib](https://pdf-lib.js.org/) をCDNから読み込みます)。
  - 完全オフラインで使いたい場合は、これらのライブラリをローカルに保存して `index.html` の `<script>` の参照先を書き換えてください。

## ローカルサーバーで開く(任意)

`file://` で直接開いても動作しますが、ブラウザによっては制限があるため、簡易サーバー経由を推奨します。

```bash
# このフォルダで
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 技術メモ

- 手書きサインは余白(透明部分)を自動的に切り取り、縦横比を保ったまま配置します(`app.js` の `trimCanvas`)。
- サインの配置位置は解像度に依存しない「視覚座標(PDFポイント, 左上原点)」で保持し、保存時に各ページの実寸・回転角を元に pdf-lib の座標系へ変換しています(`app.js` の `computePlacement`)。
- 同じサイン画像は1度だけPDFに埋め込み、複数箇所で再利用してファイルサイズを抑えています。
