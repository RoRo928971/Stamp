# 📄 PDF捺印アプリ

会社の書類(PDF)を取り込み、選択した箇所に印鑑(電子印鑑)を捺印できるブラウザアプリです。

## 特長

- **完全クライアントサイド処理** — PDFファイルはブラウザ内だけで処理され、サーバーや外部に送信されません。機密書類でも安心して利用できます。
- **2種類の印鑑** に対応
  - 電子印鑑を自動生成(丸印 / 角印、文字・色を指定)
  - 手持ちの印鑑画像(PNG / JPG)をアップロード
- **クリックで捺印**、ドラッグで移動、スライダーでサイズ調整
- **複数ページ対応**、ページの回転(90°/180°/270°)にも対応
- 捺印の取り消し・全消去、捺印済みPDFのダウンロード

## 使い方

1. このフォルダの `index.html` をブラウザで開きます。
2. **① PDFを取り込む** — PDFファイルを選択(またはドラッグ&ドロップ)します。
3. **② 印鑑を準備する**
   - 「電子印鑑を作成」タブ：文字・形・色を指定して「この印鑑を使う」を押します。
   - 「画像を使う」タブ：印鑑画像を選択します(背景が透明なPNG推奨)。
4. **③ 捺印する** — PDF上の捺印したい位置をクリックします。配置後はドラッグで移動、スライダーでサイズ変更できます。印鑑右上の「×」で個別削除できます。
5. **④ 保存する** — 「捺印済みPDFをダウンロード」を押すと、捺印を焼き込んだPDFが保存されます。

## 動作環境

- モダンなブラウザ(Chrome / Edge / Firefox / Safari の最新版)
- 表示にインターネット接続が必要です(PDF描画ライブラリ [PDF.js](https://mozilla.github.io/pdf.js/) と PDF生成ライブラリ [pdf-lib](https://pdf-lib.js.org/) をCDNから読み込みます)。
  - 完全オフラインで使いたい場合は、これらのライブラリをローカルに保存して `index.html` の `<script>` の参照先を書き換えてください。

## ローカルサーバーで開く(任意)

`file://` で直接開いても動作しますが、ブラウザによっては制限があるため、簡易サーバー経由を推奨します。

```bash
# このフォルダで
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 技術メモ

- 印影の配置位置は解像度に依存しない「視覚座標(PDFポイント, 左上原点)」で保持し、保存時に各ページの実寸・回転角を元に pdf-lib の座標系へ変換しています(`app.js` の `computePlacement`)。
- 同じ印鑑画像は1度だけPDFに埋め込み、複数箇所で再利用してファイルサイズを抑えています。
